# CineNest Portfolio

Create a premium, minimalistic portfolio website for CineNest Media, a professional video post-production agency.

IMPORTANT:

I have uploaded the official CineNest Media logo with this prompt. Use the uploaded logo as the primary visual and branding reference.

BRAND COLORS:

The logo uses three core colors:

- Deep Forest Green: #102817

- Lime Green: #B9D531

- White: #FFFFFF

Build the entire visual identity around these colors.

Do NOT introduce unrelated brand colors.

Use the deep forest green as the primary background/color foundation, white for primary typography, and the lime green selectively for accents, buttons, active states, highlights, borders, icons and interactive elements.

The overall aesthetic should feel:

- Cinematic

- Premium

- Minimal

- Modern

- Sophisticated

- Creative

- Professional

- Calm

- Visual-first

This is NOT a traditional corporate website.

This is a dedicated portfolio/showcase website where the quality of CineNest Media's work is the main focus.

--------------------------------------------------

CORE DESIGN PHILOSOPHY

--------------------------------------------------

Think of this website as a digital film gallery.

The visitor should spend most of their time looking at and experiencing the work.

Prioritize:

1. Video

2. Visual storytelling

3. Simple navigation

4. Strong typography

5. Whitespace

6. Fast and smooth interaction

Avoid:

- Excessive text

- Generic agency layouts

- Stock photos

- Unnecessary gradients

- Excessive animations

- Large blocks of text

- Clutter

- Fake statistics

- Fake testimonials

- Fake clients

- Fake portfolio projects

The design should feel expensive without being complicated.

--------------------------------------------------

NAVIGATION

--------------------------------------------------

Create a minimal sticky navigation.

Left:

CineNest Media logo

Right:

- Work

- Services

- About

- Contact

Use a subtle transparent/dark navigation background.

As the visitor scrolls, the navigation can become slightly more opaque.

Use the uploaded logo correctly and maintain its proportions.

On mobile:

Use the logo on the left and a minimal hamburger menu on the right.

--------------------------------------------------

HERO

--------------------------------------------------

Create a cinematic, minimal hero section.

Use the deep forest green background.

Headline:

"WE TURN RAW FOOTAGE

INTO STORIES WORTH WATCHING."

Supporting text:

"Cinematic video editing, color grading & post-production for creators, brands and filmmakers."

Primary CTA:

"Explore Our Work"

Secondary CTA:

"Start a Project"

Use large, elegant typography with strong hierarchy.

Use white as the primary text color.

Use CineNest lime green (#B9D531) selectively to emphasize important words or interactive elements.

Do NOT make the hero overly busy.

The hero should communicate the purpose of the company within 5 seconds.

--------------------------------------------------

FEATURED WORK

--------------------------------------------------

This is the MOST IMPORTANT section.

Heading:

"SELECTED WORK"

Supporting text:

"A selection of projects crafted through editing, color and post-production."

Create a large, visual portfolio grid.

Categories:

- Real Estate

- Weddings

- Marketing

- Social Content

Portfolio cards should be large and image/video focused.

Each project card should support:

- Thumbnail

- Project title

- Category

- Short description

- Video URL

- Optional client name

- Optional services

IMPORTANT:

I will add YouTube or Vimeo video URLs later.

Build the portfolio system so that videos can easily be added later by replacing a placeholder URL.

Do NOT create fake YouTube or Vimeo links.

For now, create elegant placeholder portfolio cards that clearly indicate where real projects will be inserted.

--------------------------------------------------

PROJECT VIEWER

--------------------------------------------------

When a portfolio item is clicked, open a premium project viewer/modal.

The viewer should contain:

- Large video player area

- Project title

- Category

- Description

- Services

- Optional client

- Close button

Design the viewer primarily for video viewing.

Make the modal feel cinematic and immersive.

Prepare the component to accept:

YouTube URLs

Vimeo URLs

Do not embed fake videos.

Make it easy for me to replace the video URL later.

--------------------------------------------------

VIDEO VIEWING EXPERIENCE

--------------------------------------------------

Because this is a video portfolio, video viewing experience is the highest priority.

Support:

- YouTube

- Vimeo

- Future direct video URLs

Use lazy loading wherever possible.

Do not load every video immediately.

Use thumbnail/poster images before playback where appropriate.

The site should remain fast even when the portfolio grows.

--------------------------------------------------

- Large cinematic headlines

--------------------------------------------------
